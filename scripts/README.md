# Проверка и сдача

- `scripts/check_all.sh [--fast] [--no-android]`: офлайн проверки, сводка PASS/FAIL/SKIP. Для каждого Python-проекта нужна его локальная `.venv`; `--fast` оставляет Python и `:core:test`, `--no-android` отключает Gradle. Проверка JSON охватывает все JSON результатов, кроме трёх указанных служебных суффиксов, поэтому диагностические JSON тоже могут не пройти схему.
- `scripts/package_submission.sh 0.1.0 --dry-run`: проверить артефакты, документы и индекс Git, ничего не создавая. Затем `scripts/package_submission.sh 0.1.0 --write --output /путь/к/новой/папке`: скопировать отслеживаемые файлы из рабочего дерева и APK, сформировать манифест и хеши в пакете. Существующий каталог не перезаписывается; публикации нет. Чек-лист предварительный — семь пунктов следует сверить с оригинальным ТЗ.
- APK, документы с `TODO(финал)`, большие файлы и веса в индексе блокируют создание пакета. APK берутся из `artifacts/apk/`, независимо от отслеживания Git; их происхождение и подпись следует проверить отдельно.
