# B48: JNI-флаги памяти llama.cpp — хостовая проверка (macOS arm64, CPU, 4 потока)

Qwen3-1.7B Q4_K_M, n_ctx 4096, «Протокол заседания» по одной расшифровке (`d1_budget`, запрос ≈ 1700 токенов, ответ ≈ 270–300 токенов) — тот же запрос, что приложение
строит для фрагмента в режиме `chunk_merge`. Запуск: `scripts/build_host_jni.sh` (JNI + llama.cpp под хост), затем
`tools/jvm-smoke … --llm-bench <gguf> <dialog> <protocol_system.txt> 4096 <default|nr|flags>` (`LlmBench.kt`; пик RSS — опрос `ps` раз в 50 мс).
Машина была нагружена (load average 10–17), поэтому секунды ориентировочные, отношения — нет.
