# Финальный прогон на Pixel 10 (07.11.2026)

Устройство: Google Pixel 10 (Android 17, SDK 37, 11,5 ГБ ОЗУ), 4 потока. APK: `neurosteno-medium-0.1.0.apk` из GitHub Release v0.1.0
(sha256 `a6d1c2be…74ef`), подписанный release, установлен свежим (`adb uninstall` + `adb install`). Запуск: `src/android/scripts/process_on_device.sh`
(`ACTION_VIEW`, ожидание `<имя>.done.json`, пик PSS — `dumpsys meminfo` раз в 2 с). Набор: те же 6 эталонов, что в `../prerelease2/`.
Оценка: `stenoeval score` (DER — с допуском ±0,25 с). Все 6 JSON проходят `stenoeval validate`.

Выводы:
- Качество на телефоне **совпадает с эмулятором** (`../prerelease2/README.md`): WER norm и DER равны с точностью до сотых; отличие только в WER punct у synth_0004 (26,48 против 24,92 — после слияния правок выжимки и ответов). Результат детерминирован, то есть цифры эмулятора переносятся на устройство.
- Скорость: RTF 0,09–0,22, **быстрее реального времени в 4,5–11 раз**; в среднем 0,144 (эмулятор: 0,075–0,133, хост был нагружен). Первая запись (0,219) включает прогрев после свежей установки.
- Память: пик PSS 516–735 МБ, падений и ANR нет.
- Оговорки те же, что на эмуляторе: `cats_c01`/`cats_c04` — «флип» числа говорящих (B57), дальнее поле и смесь языков — слабые места; WER punct английской записи 98 %, потому что Parakeet не ставит знаки.

Файлы: `<id>.json` (формат ТЗ), `<id>.full.json`, `<id>.done.json` (метрики приложения), `scores.csv`, `scores.json`, `run.log`.
