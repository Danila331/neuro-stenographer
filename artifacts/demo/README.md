Видео без закадра. Обработка показана в реальном темпе, без ускорения; вырезаны только технические паузы и неудачные касания. Экраны блокировки и посторонние файлы в монтаж не включены.

Показано:

- главный экран и импорт аудио через системный файловый диалог;
- этапы обработки и готовая расшифровка с говорящими и таймкодами;
- экспорт JSON и PDF с сохранением через системный диалог;
- плеер, переход по репликам и дорожка говорящих;
- повторная обработка выбранного фрагмента;
- запись с микрофона и живая текстовая расшифровка;
- встроенные модели, настройки и фактическая статистика Pixel: 58 секунд аудио за 11 секунд, RTF 0,19, пик PSS 678 МБ.
