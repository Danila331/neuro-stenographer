## Автоматическая запись (черновик)

```bash
artifacts/demo/record_demo.sh --serial SERIAL --file cats_c01_v0_meeting_clean.wav --out /tmp/neuro-demo --dry-run
artifacts/demo/record_demo.sh --serial SERIAL --file cats_c01_v0_meeting_clean.wav --out /tmp/neuro-demo
```

Скрипт ожидает готовый файл в `/sdcard/Download/NeuroSteno-demo/`, установленное приложение medium и подготовленные модели. `--package` меняет пакет; выходная папка должна быть новой. Экран записывается частями по 170 с, файлы копируются через `adb pull`, при наличии `ffmpeg` склеиваются. Звук и закадр нужно добавить отдельно. Скрипт меняет режим полёта и «Не беспокоить» и не восстанавливает их; при отказе системы их нужно включить вручную. Устройство сохраняет удалённые части и служебный pid-файл.

Запуск на устройстве **не проверен**: системный файловый диалог и подписи могут отличаться; возможна ручная настройка папки или селекторов. Ожидание маркера использует стандартный `results/` и не обнаруживает запасные `results-<uid>` или внутренний каталог. Скрипт останавливается при ошибке и не удаляет файлы; перед реальной записью проверьте свободное место и состояние приложения.
