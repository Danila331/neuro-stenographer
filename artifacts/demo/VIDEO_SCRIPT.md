# Сценарий готового видео (3:34,57)

Устройство: **Google Pixel 10**, release-APK `0.1.0-hard`. Запись экрана 720 × 1600, 30 fps, без закадра. Все вычисления показаны в реальном темпе.

| Сцена | Содержимое |
|---|---|
| Главный экран и импорт | «Выбрать аудиофайл» → системный выбор `cats_c01_v0_meeting_clean.wav` |
| Обработка | Прогресс, этапы декодирования, поиска речи, определения языка, ASR и диаризации; естественное ожидание |
| Расшифровка | Два говорящих, 14 реплик, таймкоды и цветовые обозначения |
| Экспорт | «Экспорт JSON» → «Сохранить»; «Другие форматы» → PDF → «Сохранить» |
| Плеер | Воспроизведение, подсветка текущей реплики, переход по тексту и дорожка говорящих |
| Повторная обработка | Меню реплики → «Обработать заново» → выбор языка и пересмотр говорящих → результат |
| Микрофон | Экран записи, таймер, уровень микрофона и живая текстовая расшифровка речи |
| Модели | Активный встроенный набор Hard 2,9 ГБ; локальная обработка; дополнительные наборы не скачиваются |
| Настройки | Язык, представление чисел, число говорящих и тема |
| Статистика | 58 секунд аудио за 11 секунд, RTF 0,19, пик PSS 678 МБ, Pixel 10 |

Монтаж удаляет только технические паузы и неудачные касания. Ни один фрагмент не ускорен. Экраны «Протокол» и «Вопрос по расшифровке» в демонстрацию не входят.

После записи на устройстве отключено отображение касаний, исходный таймаут экрана восстановлен. Экспортированные файлы выгружены в `exported/`; JSON проходит `stenoeval validate`, PDF открывается.
