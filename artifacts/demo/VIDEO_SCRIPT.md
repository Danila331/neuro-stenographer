## Запись с устройства

```bash
adb shell settings put system show_touches 1                 # показывать касания
adb shell cmd connectivity airplane-mode enable              # режим полёта (Android 11+; иначе из шторки)
adb shell screenrecord --size 720x1600 --bit-rate 8000000 --time-limit 170 /sdcard/part1.mp4   # Ctrl+C по окончании сцены
adb shell screenrecord --size 720x1600 --bit-rate 8000000 --time-limit 170 /sdcard/part2.mp4
adb pull /sdcard/part1.mp4 . && adb pull /sdcard/part2.mp4 .
adb shell settings put system show_touches 0
```
`screenrecord` пишет не больше 180 с за файл и **без звука**: запись разбиваем на части; звук плеера озвучиваем закадром.

## Склейка и озвучка (ffmpeg)

```bash
printf "file 'part1.mp4'\nfile 'part2.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy raw.mp4                       # склейка
ffmpeg -i raw.mp4 -i voice.m4a -c:v libx264 -crf 23 -c:a aac -shortest demo.mp4   # + закадр
```
Ускорить ожидание обработки при необходимости: `-filter:v "setpts=0.5*PTS"` на нужном отрезке (честно указать надпись «ускорено»).
