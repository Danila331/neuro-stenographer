# Финальная видеодемонстрация

Для сдачи используется файл `demo.mp4`, предоставленный владельцем проекта. Черновые записи и прежний сценарий монтажа больше не используются.

Технические параметры: 2 минуты 1,35 секунды, 570 × 1280, H.264, 59,94 fps, AAC, 14 968 156 байтов.

SHA-256: `bfc8dd5b4a22f01f80ed822cadc172883d444b5ac7006e6b1525e3b59f254d06`.

Отдельно проверены экспортированные на Pixel 10 JSON и PDF в каталоге `exported/`: JSON проходит `stenoeval validate`, PDF открывается.
