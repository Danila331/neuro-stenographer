# Презентация защиты — черновик

Открыть `defense.html` в браузере без сети: стрелки переключают слайды, `N` показывает заметки с источниками и `TODO(финал)`. Печать — один слайд на страницу. Пересборка из корня: `python3 artifacts/presentation/build.py`. Нужны только стандартная библиотека Python и три снимка из `artifacts/demo/screens/`.

В этой среде `python-pptx` не установлен, поэтому подготовлен самостоятельный HTML по условию задания; зависимости и CDN не используются. Данные: `docs/ARCHITECTURE.md`, `docs/TEST_RESULTS.md`, `docs/MODELS.md`, `docs/BACKLOG.md`, `docs/DEFENSE.md`, `docs/LIMITATIONS.md`. Замеры относятся к указанным прогонам, а не к ещё не выпущенному APK. Заметки у каждого слайда уточняют источник. Финальные результаты и скриншоты необходимо заменить после сборки и прогонов.
