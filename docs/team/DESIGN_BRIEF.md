# Дизайн-бриф: редизайн «Нейро-стенографист» (B52)

**Стиль:** нео-брутализм / неопанк. Контрастно, графично, «по-взрослому», без глянца.
- Основа — **белый фон, чёрный текст и толстые чёрные обводки** (2–3 dp), «жёсткие» тени со смещением
  без размытия, прямые углы или малые радиусы, крупная типографика, моноширинный шрифт для таймкодов.
- Тёмная тема — инверсия: чёрный фон, белый текст и обводки.
- **Один неоновый акцент.** Кандидаты: кислотно-зелёный (≈ `#B6FF00`) и неоново-розовый (≈ `#FF2E88`).
  Выбрать по скриншотам обоих вариантов в светлой и тёмной теме и по контрасту (WCAG AA): акцент —
  заливки, выделения, активные состояния; текст на акценте — чёрный. Второй цвет — только если без
  него не обойтись.
- **Цвета говорящих:** набор из 6–8 различимых неоновых заливок с чёрным текстом, согласованный с акцентом.
- Шрифты — свободные (OFL), вшитые в APK, офлайн. Например, Space Grotesk / Unbounded для заголовков и
  JetBrains Mono для времени; выбрать и проверить кириллицу.

**Обязательно сохранить** (автопроверка жюри — «чёрный ящик»):
- путь «Выбрать аудиофайл → обработка → расшифровка → Экспорт JSON» без лишних шагов;
- подписи и `resource-id` кнопок `btn_pick_audio`, `btn_record`, `btn_cancel_processing`, `btn_export_json`;
- VIEW/SEND-интенты, автосохранение, маркеры `.done.json`.
Все экраны: главный, обработка, расшифровка с плеером, лист фрагмента, экспорт, протокол и вопросы,
поиск (B51), выжимка (B50), модели, настройки, статистика, запись. Доступность: контраст, крупный шрифт,
`contentDescription`. Результат — скриншоты «до/после» в `artifacts/demo/screens/redesign/`.
