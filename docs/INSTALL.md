# Установка и использование

## Требования к устройству

| | |
|---|---|
| Архитектура | **ARM64** (arm64-v8a); x86-эмуляторы не поддерживаются |
| Android | 8.0+ (minSdk 26), целевой 15 (targetSdk 35) |
| RAM | рекомендуется 4 ГБ; обработка без LLM укладывается в ≈0,5 ГБ PSS (замер на эмуляторе jury-4g, `docs/TEST_RESULTS.md`) |
| LLM (протокол, вопросы) | ≥ 3 ГБ RAM и ARM с `dotprod`; иначе кнопка недоступна, причина показана текстом, расшифровка работает |
| Память | свободное место ≈ размер APK ещё раз: при первом запуске модели копируются из APK в память приложения (освобождается кнопкой «Удалить встроенный набор») |
| Сеть | не нужна (только для скачивания наборов в «Моделях») |

## Установка APK

APK лежат в `artifacts/apk/` (TODO(финал): итоговые файлы и sha256). Для жюри — `neurosteno-medium-<версия>.apk`.

- **adb:** `adb install -r artifacts/apk/neurosteno-medium-<версия>.apk` (на эмуляторе — тот же ключ `adb`).
- **Вручную:** скопировать APK на устройство, открыть в файловом менеджере, разрешить установку из этого источника.
  APK подписан локальным ключом, не Google Play: предупреждение системы ожидаемо.
- Варианты ставятся рядом (разные `applicationId`: `ru.neurosteno.app.lite|medium|hard|online`).

## Первый запуск

Приложение открывается сразу на главном экране: онбординга, обязательных диалогов и разрешений нет. Модели при первом
запуске копируются из APK (полоса «подготовка моделей»). Вариант `online` единственный показывает экран выбора и
скачивания набора (нужен интернет один раз).

## Использование

| Шаг | Действие |
|---|---|
| Импорт | **«Выбрать аудиофайл»** (или «Открыть с помощью»/«Поделиться» из другого приложения) |
| Запись | **«Записать»**: разрешение микрофона запрашивается только здесь; по остановке запись обрабатывается |
| Обработка | сама; видны общий %, оставшееся время, стадии, «Отменить»; можно свернуть (уведомление) |
| Расшифровка | реплики с цветом говорящего и временем; поиск по тексту |
| Плеер | play/pause, ±10 с, скорость 0,75–2×; тап по реплике — переход и воспроизведение |
| Правка | меню реплики: текст, смена говорящего, объединить, удалить; отмена правок; иконка «говорящие» — переименование |
| Экспорт | **«Экспорт JSON»** — файл по ТЗ; «Другие форматы»: TXT, SRT, VTT, расширенный JSON, «Поделиться» |
| Протокол | кнопка протокола: «Протокол заседания» и «Вопрос по расшифровке» (локальная LLM, потоковый вывод) |
| Модели | скачать набор (прогресс, докачка, sha256), сделать активным, удалить встроенный, восстановить из APK |
| Настройки | язык (Авто/Русский/English), число говорящих (Авто/1–8), тема, очистка истории; статистика обработки: RTF, память, стадии |

В JSON по ТЗ говорящие всегда `speaker_N`, имена из переименования попадают только в TXT/SRT/VTT и расширенный JSON.

## Автоматизация (без UI)

- `ACTION_VIEW`/`ACTION_SEND` с `audio/*` запускают обработку сразу:
  `adb shell am start -a android.intent.action.VIEW -d file:///sdcard/Android/data/<pkg>/files/<файл>.wav -t "audio/*" -n <pkg>/ru.neurosteno.app.MainActivity`
- Результат сохраняется сам в `/sdcard/Android/data/<pkg>/files/results/<имя>.json` (+ `<имя>.full.json`;
  `<имя>.done.json` — маркер готовности с RTF и пиком памяти, `<имя>.error.json` — сбой). Забрать: `adb pull`.
- Готовый сценарий (установка, запуск, ожидание, выгрузка, замер): `src/android/scripts/process_on_device.sh <apk> <audio> [out]`.
- Стабильные подписи/`resource-id` для UI-автоматизации: `btn_pick_audio`, `btn_record`, `btn_cancel_processing`, `btn_export_json`.

## Сборка из исходников

Нужны JDK 17, Android SDK, NDK, CMake; скрипты ставят всё в `$ROOT/.local` (вне git). Лицензии SDK принимает пользователь.

```bash
source scripts/env.sh                         # JAVA_HOME, ANDROID_HOME, PATH
src/android/scripts/sdk_setup.sh              # SDK, NDK, образ эмулятора (после sdkmanager --licenses)
python3 scripts/fetch_models.py --tier medium # модели -> $ROOT/.cache/models (только официальные источники)
scripts/stage_models.sh medium                # кэш -> assets варианта + manifest.json (размеры, sha256)
scripts/build_all.sh                          # lite, medium, hard, online -> artifacts/apk/ (подпись локальным ключом)
```

## Тесты и паритет

```bash
cd src/android && ./gradlew :core:test :app:testMediumDebugUnitTest      # JVM-тесты (core, UI-логика, загрузчик)
scripts/emulator.sh jury-4g && src/android/scripts/smoke_apk.sh <apk>    # установка и запуск на AVD (4 ГБ, 4 ядра, без GPU)
src/android/scripts/parity.sh ru-dialog-tts-cats 10 medium               # Android == Python-эталон (допуск 1 п.п. WER)
cd src/eval/stenoeval && .venv/bin/pytest -q                             # метрики; методика — docs/TEST_RESULTS.md
```
Датасеты: `src/eval/datasets/make_all.sh`; эталонный пайплайн: `src/eval/refpipe/README.md`.
