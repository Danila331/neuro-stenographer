# Минималистичная версия Android

Ветка `codex/minimal-design`, исходная версия — коммит `3920d76` в `main`.
Старый интерфейс и его готовые APK сохранены. Новая версия устанавливается рядом:

| | Исходная версия | Минималистичная версия |
|---|---|---|
| Пакет medium | `ru.neurosteno.app.medium` | `ru.neurosteno.minimal.medium` |
| Название | Нейро-стенографист Medium | Нейро · Записи |
| Данные | собственная история | отдельная история |

## Дизайн

Тёплый фон `#FAF9F6`, белые поверхности, графитовый текст, шалфейные акценты.
Тёмная тема — приглушённый зелёно-графитовый фон. Голоса различаются пастельными метками,
именами и круглыми индикаторами. Цвет не является единственным способом различить говорящих.

Обводки — до 1 dp, скругления карточек 18 dp, кнопок и полей 12 dp, листов 24 dp.
Жёсткие тени и декоративные подчёркивания убраны. Заголовки и текст используют Golos Text;
таймкоды — JetBrains Mono. Основные кнопки и иконки сохраняют область нажатия от 48 dp.

| Экран | Изменение |
|---|---|
| Главный | спокойный заголовок, импорт и запись в одной строке, карточки истории, пустое состояние |
| Расшифровка | пастельные говорящие, удобочитаемый текст, три компактных инструмента, мягкая подсветка |
| Плеер | круглая кнопка воспроизведения, тонкий ползунок, дорожка без чёрных рамок |
| Запись и живой текст | спокойный таймер, тонкий индикатор уровня, нейтральная панель превью |
| Обработка и ошибка | нейтральный процент, небольшие индикаторы стадий, закреплённая отмена |
| Протокол и вопросы | мягкие вкладки, спокойная типографика, ответы в пастельных карточках |
| Выжимка | темы, решения и задачи с ненавязчивыми метками; одна кнопка повтора при ошибке |
| Поиск | мягкие поля и фильтры, читаемое выделение и ссылки в обеих темах |
| Настройки | секции с короткими пояснениями, аккуратный выбор языка, участников и темы |
| Модели и первый запуск online | единые скруглённые карточки и спокойные статусы |
| Статистика | тонкие графики и разделители, спокойные числовые значения |
| Лицензии и полный текст | скруглённые карточки, аккуратная иерархия текста |
| Редактирование, экспорт, пересчёт | общие скруглённые диалоги, меню и нижние листы |

## Границы изменений

Модули `core`, `audio`, `engine-*`, `store-objectbox`, Python-эталон и конфигурации моделей
не изменены. Контракты экранов, навигация, обработка и форматы экспорта сохранены.
Истории двух установок независимы; автоматическая миграция данных не выполняется.

## Сборка

Из рабочей копии этой ветки:

```bash
scripts/stage_models.sh medium
NO_STAGE=1 scripts/build_all.sh medium
source scripts/env.sh
cd src/android
./gradlew --offline --max-workers=2 :core:test :app:testMediumDebugUnitTest
```

Рабочая копия: `.worktrees/codex-minimal-design` внутри основного репозитория.
Общие инструменты и модели берутся из `.local` и `.cache` основного репозитория.
Локальные копии зависимостей можно подготовить штатными `fetch_sherpa_onnx.sh` и `fetch_llama_cpp.sh`.

Скриншоты, галерея и результаты проверки — `artifacts/demo/minimal/`.

Для повторного просмотра подготовлен отдельный AVD `minimal-review`. После `source scripts/env.sh`
его можно открыть командой `emulator -avd minimal-review -gpu swiftshader_indirect`.
