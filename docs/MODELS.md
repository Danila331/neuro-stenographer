## Почему GigaAM v3 RNNT с пунктуацией

Сравнение на ПК (Mac M3 Pro, sherpa-onnx, int8, 4 потока), **тестовые** части наборов, WER в %.
Источник: `src/eval/bench_asr/results/final/SUMMARY_ru.md` (dev-части там же), память — `final/mem.jsonl`
(чистый процесс, чанк 25 с, пик RSS).
«Знаки» = `pc_sep_num`: знаки и регистр учитываются (е=ё), числа словами. «Без знаков» = `norm_num`.

| Модель | ru-asr-dev (фразы), без знаков | диалоги synth, без знаков | диалоги cats, без знаков | synth, знаки | cats, знаки | Пик RSS |
|---|---|---|---|---|---|---|
| **GigaAM v3 RNNT punct** | 7,18 | 16,77 | 22,96 | **30,83** | **32,54** | 483 МБ |
| GigaAM v3 RNNT | 5,63 | 17,57 | **20,08** | 45,86 | 54,65 | 480 МБ |
| GigaAM v3 CTC punct | 7,39 | 17,46 | 25,09 | 33,18 | 40,14 | 470 МБ |
| GigaAM v3 CTC | 5,84 | 19,91 | 23,34 | 47,43 | 56,52 | 467 МБ |
| GigaAM v2 CTC | 6,15 | 18,09 | 24,34 | 46,31 | 57,94 | 867 МБ |
| Zipformer-ru (int8) | 9,58 | 23,74 | 26,85 | 49,66 | 58,99 | 635 МБ |
| Parakeet-TDT-0.6B v3 (мультиязычная) | 14,70 | — | — | 24,93 (ru-asr-dev) | — | 1503 МБ |
| FastConformer multi CTC | 15,56 | — | — | 28,24 (ru-asr-dev) | — | 712 МБ |

Выводы:
- GigaAM v3 лучшая на русской речи: на фразах WER 5,6–7,4 % против 9,6 % у Zipformer и 14,5–15,6 % у мультиязычных моделей; на диалогах лучшая или в пределах 3 п.п. от лучшей.
- Решающий фактор — **знаки**: жюри ответило, что пунктуация входит в оценку, интонация — эталон, е/ё не различаются
  (Q13, Q14, `docs/BACKLOG.md`; трактовка «знаки входят в WER» — вывод из контекста, B27 не подтверждён). Модель со встроенной пунктуацией даёт 30,8 % против 45,9 % на synth и 32,5 % против 54,7 % на cats.
- Цена: без учёта знаков на cats 22,96 против 20,08 (+2,9 п.п.). Если жюри знаки не считает, мы теряем ~3 п.п. WER.
- Модель пишет числа цифрами; если эталон жюри словами, потеря ≈5,5 п.п. (B29). Режим «числа → слова» готов, решение после ответа жюри (B27).
- Скорость: RTF 0,023 (чанк 25 с, 4 потока, ПК, относительная величина: машина была загружена); Whisper-turbo — 0,211.

Параметры: чанк 25 с — компромисс (30 с точнее на 0,5 п.п., но пик RSS +60 МБ; `bench_asr/results/chunk_cats_dev.jsonl`), порог VAD 0,45, слова — по токенам с временем (метки: `src/eval/refpipe/README.md`).
Английский: Parakeet-TDT-110m — WER 6,64 % (FLEURS en, 200 фраз) против 9,93 % у FastConformer multi-RNNT и 12,43 % у Moonshine base
(`results/matrix_en.md`). Определение языка Whisper-tiny: точность 96 % (ru) / 99 % (en) на 10 с, 89,5 % / 97 % на 2 с
(`final/lid_full.jsonl`); в смешанных диалогах определение по первым 10 с файла верно в 40 % файлов (n=5), по фрагментам — 83–100 %,
поэтому язык определяется по каждому фрагменту (B30, `language.per_chunk`).

## Что отвергнуто и почему

| Решение | Результат | Причина |
|---|---|---|
| Zipformer-ru | WER 9,58 % против 5,63 % на фразах, 26,85 против 20,08 на cats; без знаков (59 % со знаками) | быстрее (RTF 0,008), но вдвое хуже по точности |
| Whisper large-v3-turbo вторым проходом | один turbo — 9,77 % против 4,19 % у GigaAM (166 фраз ru-dev); перераспознавание 10 % наименее уверенных фраз — 4,86 % (хуже основной); оракул 3,63 % — только верхняя граница | пик RSS 2,7 ГБ, RTF 0,21; выбор фраз по уверенности не работает (`final/second_pass_rudev.md`, `final/mem.jsonl`) |
| Несколько ASR + голосование (ROVER) | 3,80 % против 4,19 % у одной модели (GigaAM+Whisper-turbo+GigaAM CTC) | −0,4 п.п. за кратный рост времени и памяти |
| Whisper как основная модель | 9,77 % против 4,19 % (ru-dev) | хуже по WER; в sherpa-onnx нет меток токенов (слова раскладываются пропорционально), 2,7 ГБ RSS |
| Мультиязычная одна модель (Parakeet v3, FastConformer) | 14,70 % и 15,56 % на ru-dev | втрое хуже русского GigaAM; v3 — 1,5 ГБ |
| Hotwords («Котовице», имена) | на диалогах cats 26,0 % против 29,0 % без них (лучший режим) | работают только на RNNT без пунктуации, с punct-моделью невозможны (B23) |
| Пунктуация LLM | F1 знаков Qwen3-0.6B 0,75 против 0,86–0,88 у RUPunct (llm-bench, предв.); с LLM на пути обработки пик PSS 2,1 ГБ и RTF 0,75 против 0,5 ГБ и 0,33 (эмулятор jury-4g, замер 2026-11-07) | модель со встроенными знаками точнее, быстрее и не меняет слова; LLM вынесена из основного пути |
| Знаки по паузам (просодия) | 23–25 % со знаками на фразах против 15–16 % у GigaAM punct (`final/prosody.md`) | уступает встроенной пунктуации |
| Нормализация громкости | на тихих записях WER 35 % → 13 % (−44 дБ), но в сквозном пайплайне ухудшает VAD (synth 40,2 → 46,8 %) | выключена, TODO(финал): решение по совместному перебору с порогом VAD |

LLM: кандидаты Qwen3 0,6B/1,7B/4B (Apache-2.0, русский, GGUF в llama.cpp); размер выбран по памяти 4 ГБ (B19: Qwen3-0.6B Q8 даёт
~1,5 ГБ пик из-за repack). TODO(финал): итоги llm-bench (качество протокола по размерам).
