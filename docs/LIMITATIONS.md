# Ограничения решения

## Поддерживаемые условия

| | |
|---|---|
| Языки | русский (основной), английский; смесь определяется по фрагментам |
| Входные файлы | любые форматы, которые декодирует Android (MediaCodec); моно/стерео сводится в моно 16 кГц |
| Сценарии | встреча на диктофон и быстрый разговор/звонок, 1–8 говорящих (число — авто или вручную) |
| Устройство | ARM64, Android 8+, ориентир 4 ГБ RAM; без GPU/NPU (по умолчанию только CPU) |
| Сеть | не нужна; интернет только для скачивания наборов моделей по кнопке |

## Известные ограничения

| Ограничение | Подробности |
|---|---|
| Перекрывающаяся речь | распознаётся один поток: слова одновременно говорящих теряются или приписываются одному; на `cats_c04_call_overlap` (эмулятор) WER norm 25,5 % против 12,8 % на чистой `cats_c01` (`docs/TEST_RESULTS.md`) |
| Короткие реплики | «да/угу/ага» на фоне VAD теряются в 3–12 % случаев (B31); короткие чанки (≤ 2 букв) отбрасываются как галлюцинации на шуме и мяуканье |
| Английский | отдельная модель (Parakeet-110m, WER 6,64 % на чтении FLEURS); диалоговых английских замеров на целевых условиях нет; пунктуации на английском нет |
| Тихие и дальние записи | усиление громкости применяется только для ASR (`scope=asr`), дозабор речи (`vad.rescue`) помогает; шумоподавление, AGC и dpdfnet на дальнем поле не помогают или вредят, остаток удалений — предел модели (B55) |
| Число говорящих | оценивается по силуэту кластеров: у 18 из 115 файлов при малых изменениях слов число «флипает» (почти равные силуэты), поэтому выбросы DER ±20–40 п.п. на отдельных файлах (B57); общей правки без потери точности не нашли |
| Монологи | защита от ложных говорящих (порог силуэта 0,30, выбран в пользу диалогов): монологи 19,8 → 22,3 % DER; запись `mono_00` даёт 2–3 говорящих (B53, B57) |
| Числа | модель пишет цифрами (в настройках есть «цифрами / словами»); если эталон жюри словами, WER на ≈5,5 п.п. выше (B29); режим «слова» готов, не включён |
| Скорость диаризации | на старой сборке росла быстрее длины записи (Pixel 10: 882 → 2524 мс при ×2,1, B35); с `window_shift_ratio` 1,0 сегментация быстрее ×10 (B46), на Pixel не перемерено — TODO(финал) |
| LLM | нужна ОЗУ ≥ 3 ГБ и ARM с `dotprod`; малые модели Qwen3 могут искажать детали протокола и ответов (в lite протокол помечен «черновой») — результат нужно проверять по расшифровке |
| Выжимка | скорость на телефоне ≈ 0,85× длительности записи — **оценка по множителям, не замер на устройстве** (`src/eval/bench_rag/README.md`); сначала показывается быстрая версия без LLM; экраны — TODO(финал) |
| AI-поиск | в работе (TODO(финал)); векторная БД ObjectBox — нативная библиотека закрытая (бесплатная), API Apache-2.0 (B56); запасной путь — перебор без ObjectBox; в `online` без эмбеддингов поиск работает на BM25 |
| Размер | release-APK: lite 935 МиБ, medium 1,7 ГиБ, hard 2,9 ГиБ, online 47 МиБ (B53); при первом запуске модели копируются в память приложения — нужно столько же свободного места; hosting APK > 100 МБ в git невозможен, ссылка на Release — TODO(финал, B49) |
| Hard | на 4 ГБ не помещается (LLM 4B), на автопроверку не предназначен |

## Данные и методика оценки

- **Тестовые данные синтетические или собраны из чтения.** `ru-dialog-synth` — реальные дикторы, склеенные в диалоги; `ru-dialog-tts-cats` — голоса TTS;
  настоящих диалогов с перебиваниями нет, записи пользователя (`real`) пока не размечены (B25). Метрики на них оптимистичнее реальных:
  голоса чистые, у каждого диктора свой микрофон (`src/eval/datasets/README.md`, «Известные слабости»).
- **Методика жюри неизвестна.** Подтверждено только, что пунктуация «входит», интонация — эталон, е/ё не различаются (Q13, Q14).
  Не подтверждены (B27): считается ли знак отдельным токеном, регистр, запись чисел. Поэтому WER считаем в нескольких режимах.
- Скорость на ПК — относительная (общая загруженная машина); на устройстве измерена на эмуляторе jury-4g и Pixel 10 (`docs/TEST_RESULTS.md`).

## Что не входит в текущую версию

- Точная потоковая расшифровка: во время записи показывается только набросок без знаков и говорящих, итог — после остановки.
- Аппаратное ускорение (NNAPI/GPU) — только как опция с откатом на CPU, не включено (B38, нужен замер на телефоне).
- Шумоподавление (GTCRN) — модель в сборке, по умолчанию выключено.
- Языки кроме русского и английского; смена языка внутри одной реплики.
- Облако, аккаунты, синхронизация: всё хранится в приватной папке приложения.

## Риски демонстрации

| Риск | Что делаем |
|---|---|
| Долгая обработка длинной записи на слабом устройстве | показывать запись до 1–2 мин; приложение показывает ожидаемое время и стадии |
| Ошибки в неразборчивых местах («котовица», имена) | честно называть WER, показывать правку и переименование |
| LLM медленная/ошибается | запускать после показа расшифровки, показывать потоковый вывод; на слабой RAM есть понятное сообщение |
| Первый запуск копирует модели из APK | сделать до показа, прогреть приложение |
| Нет сети на площадке | демонстрация работает офлайн; для менеджера моделей нужна сеть — показывать на предзагруженном экране или видео |
| Расхождение метрик с жюри | показать несколько режимов WER и объяснить методику |

## Дальнейшее развитие
