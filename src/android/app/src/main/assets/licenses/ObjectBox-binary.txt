ObjectBox -- лицензионная справка

ВНИМАНИЕ: в приложение вложена краткая справка, а не полный текст бинарной лицензии ObjectBox GmbH (локального текста нет).

Компоненты (версия 5.4.2):
  - Java/Kotlin API ObjectBox (io.objectbox:objectbox-android, objectbox-kotlin) -- лицензия Apache-2.0 (полный текст: Apache-2.0).
  - Нативная библиотека libobjectbox-jni.so (хранилище и векторный индекс HNSW) -- ЗАКРЫТАЯ, распространяется по бинарной
    лицензии ObjectBox GmbH (разрешает использование в приложениях; исходный код недоступен).
  - Генератор кода (io.objectbox:objectbox-processor) используется только при сборке проекта и в приложение не входит.

Если бинарная лицензия неприемлема, приложение переключается на встроенное хранилище векторов в памяти (search.store.fallback = bruteforce)
без потери функций поиска.

Сведения о лицензии и FAQ: https://objectbox.io/faq/
Исходный код открытых частей: https://github.com/objectbox/objectbox-java
