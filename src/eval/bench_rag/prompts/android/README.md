# Промпты и грамматики B50/B51 (для `src/android/app/src/main/assets/prompts/`)

| Файл | Назначение | Как использовать |
|---|---|---|
| `summary_system.txt` | выжимка одного фрагмента (одна тема) → JSON | ChatML system; user = строки `[N] мм:сс Говорящий K: текст`, **N — локальный номер в фрагменте с 1** |
| `summary.gbnf.tmpl` | грамматика JSON этого ответа | подставить `{POINTS}`, `{REF_ALL}`, `{SPK_RULES}` (см. заголовок файла); пример результата — `summary.gbnf.example` |
| `summary_overview_system.txt` | 1–2 предложения «о чём разговор» по заголовкам и решениям тем | user = строки `- Тема: пункт; пункт`, до 120 токенов, без грамматики |
| `search_answer_system.txt` | ответ по найденным фрагментам со ссылками `[мм:сс, Говорящий N]` | user = `Фрагменты:\n…\n\nВопрос: …`; «Запись: название» перед группой, если записей несколько |

Сэмплинг greedy; Qwen3 с пустым блоком `<think>\n\n</think>\n\n` (как `PromptBuilder.chatml`). Эталон сборки — `bench_rag/summary.py` (`line`, `grammar`), `bench_rag/answer.py` (`context`, `verify`).
Что пробовали и отвергли: пример в `summary_system.txt` с пустыми `decisions/tasks` (меньше выдуманных поручений, но полнота решений 0.45 против 0.61); пример и «своими словами» в ответе поиска (верных ответов 0.46 против 0.66, 1.7B).
